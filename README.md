# UNTONE KALINKIN — портфолио

React, TypeScript и Vite: главная и четыре страницы кейсов. Локальные изображения и шрифты, без серверной части.

## Запуск

Node.js 22.18+ (включая запуск тестов TypeScript без дополнительного загрузчика).

```sh
npm ci
npm run dev -- --port 5173
```

Предпросмотр: http://127.0.0.1:5173/ .

```sh
node --test tests/contacts.test.mjs
npm run build
npm run preview
```

## Контент

`src/content.ts` — тексты, контакты, изображения, страницы кейсов и следующий проект.
`public/assets` — оригиналы изображений, логотипы и локальные шрифты.
`src/style.css` — оформление, адаптация и эффекты карточек.

CV и Telegram принимают полные HTTP(S)-адреса, Email — адрес почты. Пустые или некорректные значения остаются неактивными. Оба Telegram-контакта используют одно поле.
Карточки открывают кейс целиком. Внутренние переходы используют историю браузера и короткое затухание; настройки уменьшения движения учитываются. Первый кейс использует статичную обложку.

## Сборка и публикация

Результат сборки — `dist`. Dev-сервер доступен только на 127.0.0.1. При будущей публикации нужно настроить fallback на index.html для адресов /cases/* и HTTPS/защитные HTTP-заголовки на хостинге. Публикация не выполнена.

## GitHub Pages: iamuntone-web.github.io

Создайте публичный репозиторий `iamuntone-web.github.io` в аккаунте `iamuntone-web`. Исходники проекта должны лежать в корне репозитория (package.json, src, public, scripts, .github). Не загружайте node_modules.
В Settings → Pages → Build and deployment выберите Source: GitHub Actions.
Workflow `.github/workflows/pages.yml` публикует сборку при обновлении main или ручном запуске.
Скрипт `scripts/pages.mjs` создаёт HTML для каждой страницы кейса и 404.html.
Адрес после успешной публикации: https://iamuntone-web.github.io/ .
Свой домен можно подключить позднее в Settings → Pages и через DNS регистратора.
